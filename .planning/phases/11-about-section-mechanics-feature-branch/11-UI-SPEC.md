# Phase 11: UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Baseline rule (from CONTEXT.md D-11, user-preferred):** this phase invents no new visual language. It moves the homepage `.about*` / `.team*` / `.grid` rules from `src/app/page.module.css` into `src/app/about/page.module.css` and reuses existing components. Only three things are new: the `/about` page `h1`, the serif Mission lead line, and the homepage "More about us" link. Everything below is grounded in `src/styles/tokens.css` and the existing CSS Modules.

**Token rule for moved CSS:** when rules move, replace hex literals with the equal-valued *primitive* palette tokens (`#f5f2eb` -> `var(--color-paper)`, `#0a1628` -> `var(--color-black)`, `#d4a012` -> `var(--color-amber)`). Do NOT swap them for semantic tokens (`--color-background`, `--color-text-primary`): those flip in dark mode and would change today's look (the About band stays paper and the Team band stays black in both themes, exactly as on the homepage now). Rendered output must be pixel-identical to the current homepage sections.

### Layout contract: `/about` (`src/app/about/page.tsx` + `page.module.css`)

```
div.about            paper band; padding 7rem 1.5rem 6rem 1.5rem (top raised from 6rem to clear the fixed nav)
  div.aboutInner     max-width 42rem, centred
    h1.pageTitle     "About us"
    section#mission  margin-top 3rem; scroll-margin-top 6rem
      h2.aboutHeading  "Mission"
      div.aboutText
        p.lead       Mission lead sentence
        p            Mission body
    section#history  margin-top 4rem; scroll-margin-top 6rem
      h2.aboutHeading  "History"
      div.aboutText  4 paragraphs
section#team.team    black band; padding 6rem 1.5rem; scroll-margin-top 4rem
  div.teamInner      max-width 64rem, centred
    h2.teamHeading   "Team"
    div.grid         3 cols > 64rem, 2 cols 40-64rem, 1 col < 40rem (existing breakpoints)
```

- `scroll-margin-top` rationale: nav is 65px. Mission/History have no inner top padding, so 96px leaves ~31px of air above the section. The Team band carries its own 96px top padding, so 64px lands the band edge at the nav's bottom edge.
- `.pageTitle`, `.lead`, `section` margins and `scroll-margin-top` are the only new rules in this module; everything else is moved verbatim (with the token rule above). `h1` and sections set their own margins so base-layer heading margins (`* + h2 { margin-block-start: 1.5em }`) do not leak in; the module is unlayered and wins.
- After the move, delete `.about`, `.aboutInner`, `.aboutHeading`, `.aboutText`, `.emphasis`, `.team`, `.teamInner`, `.teamHeading`, `.grid` and its media queries from `src/app/page.module.css`.

### Layout contract: profile page (`src/app/about/team/[slug]/page.tsx`)

  Breadcrumbs        Home > About us > {member.name}   (existing component, left-aligned in 72rem container like event pages)

- Arithmetic: 65px nav clearance + ~37px breadcrumb row (8px + 21px line + 8px) + 8px card padding = photo top at ~110px, versus 112px today. The card must not sit lower than today (D-15). Confirm on the Cloudflare preview.
- `.profile` lives in a new co-located `src/app/about/team/[slug]/page.module.css` (one rule).

## Typography

Sizes declared for elements this phase creates or moves (exactly 4):

| Role | Size | Weight | Line Height | Applies to |
|------|------|--------|-------------|------------|
| Body | 16px (`1rem`) | 400 | 1.6 (`--leading-relaxed`) | Mission body, History paragraphs (existing `.aboutText`); "More about us" link |
| Lead | 24px (`1.5rem`) | 700 | 1.25 (`--leading-snug`) | Mission lead sentence `p.lead` |
| Heading | `clamp(1.75rem, 4vw, 2.25rem)` (28px to 36px) | 700 | 1.25 (base `h2`) | `h2` Mission, History, Team (existing `.aboutHeading` / `.teamHeading`) |
| Display | `clamp(2rem, 5vw, 3.5rem)` (32px to 56px) | 700 | 1.1 (`--leading-tight`) | `h1` "About us" `.pageTitle` (same size scale as homepage `.statement`) |

Weights declared: 400 (regular) and 700 (bold). Two weights only.

Rules:
- **`.lead`** echoes the homepage `.statement` (D-10): `font-family: var(--font-serif)`, `font-weight: 700`, `text-wrap: balance`, `color: var(--color-black)` (full opacity, overriding `.aboutText`'s 85%). Size is held at 24px, not the hero's 56px, so the hierarchy reads `h1 > h2 > lead > body` inside the 42rem column. Line height 1.25 because the sentence wraps to two or three lines at this measure.
- **`.pageTitle`**: `font-family: var(--font-serif)`, `font-weight: 700`, `line-height: 1.1`, `color: var(--color-black)`, `margin: 0`. Its explicit `font-size` overrides the base-layer responsive `h1` sizes.
- **`.moreLink`**: `font-size: 1rem`, `font-weight: 400`, `color: var(--color-paper)`, underline kept from base `a` (offset 0.15em, 1px); `:hover` `color: var(--color-amber)`. Focus ring comes from base `a:focus-visible`; do not override.
- Pre-existing styles reused unchanged and NOT part of the declared set: hero `.because` (600, amber), `MemberCard` name (18px/600) and title (14px/500), `Breadcrumbs` (14px/400), `Nav` links (14px/500), `BusinessCard` internals. Do not restyle them in this phase.

## Accessibility Contract

- One `h1` per page: `/about` = "About us"; homepage keeps "European Resolve is being built."; profile page keeps the member name `h1` from `BusinessCard`. Heading order on `/about`: h1 > h2 (Mission, History, Team) > h3 (member names inside `MemberCard`).
- Sections are plain `<section id=...>`; no `aria-labelledby` needed.
- Contrast: black text on paper and paper/amber on black are existing pairings (all above 4.5:1). Mission body keeps the existing 85% black on paper.
- Focus ring is the base amber ring; no component overrides it.
- No motion is introduced; `prefers-reduced-motion` handling stays as in `base.css`.
- `MemberCard` images keep `alt={member.name}`.
